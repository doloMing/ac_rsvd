# Mathematical and Numerical Contract

This document is the source of truth that the implementation must preserve. It
separates exact-arithmetic claims from finite-precision safeguards so that the
software does not accidentally advertise a stronger guarantee than it checks.

## 1. Problem contract

For a matrix-free real operator `A` with shape `m x n`, the user supplies an
absolute Frobenius tolerance `tau > 0` and failure level `0 < delta < 1`. The
algorithm chooses an output rank and returns a compact factorization whose exact
mathematical target is

`P(||A - U Sigma V^T||_F > tau) <= delta`.

Version 0.1 uses FP64 and CPU execution. The core never requires explicit
storage of `A`; it receives block operations for `A X` and `A^T Y`.

## 2. State and invariants

The exact algorithm maintains:

- the used input subspace `C_t` and an orthonormal basis for it;
- the retained output basis `Q_t` and projector `P_t = Q_t Q_t^T`;
- unused input dimension `d_t = n - dim(C_t)`;
- residual operator `E_t = (I - P_t) A` and energy `mu_t = ||E_t||_F^2`;
- used-subspace leakage `ell_t = ||E_t C_t||_F^2`.

The exact invariant is `range(Q_t) = A C_t`, hence `ell_t = 0`. The general
certificate formulas retain `ell_t` because a finite-precision implementation
must conservatively bound leakage rather than silently assume it is zero.

Each nonterminal sampled direction must be added to the input subspace. Each
nonzero output residual must add exactly one retained output direction. No
Householder completion created after a zero or thresholded diagonal may enter a
stopping decision or the final range.

## 3. Ordered block processing

A new block is generated by projecting a Gaussian panel against the used input
basis and applying fixed-order, unpivoted Householder QR. The resulting ordered
Haar frame is multiplied by `A` in one block operation. A second fixed-order QR
is applied after projection against the current output range.

The implementation must expose each block column to the stopping state machine
in the original sampled order. After any accepted prefix, its projector,
current residual norm, QR diagonal, and observation must agree with sequential
orthogonalization up to the documented floating-point error bounds.

For direction `omega_t`, the observation is

`X_t = d_t ||(I - P_t) A omega_t||_2^2`.

It measures the residual before the current product changes the range.

## 4. Certificate contract

For `d >= 2`, let `B` have distribution `Beta(1/2, (d - 1)/2)` and define

`Phi(d, s) = E exp(s d B)`.

The certificate is a nonnegative mixture over start times and positive scale
parameters. Default settings are:

- `J = 1 + ceil(2 log2(n))`;
- `gamma_j = 2^(-(j - 1)) / 3`;
- uniform scale weights;
- harmonic start weights `a_t = 1 / ((t + 1) H_(n - 1))`.

The online calculation evaluates only the proposed residual `c = tau^2` and
stops at the first eligible round where `W_t(tau^2) >= 1 / delta`. It stores all
scalar observations required to replay the mixture. After stopping, monotone
continuous inversion computes

`U_t = inf { c > 0 : W_t(c) >= 1 / delta }`.

The inversion changes no matrix-product count and must not change the stopping
round. The production calculation works in the log domain. A finite-precision
stop is permitted only when a lower enclosure certifies the boundary crossing;
the returned residual bound is the upper endpoint of a certified inverse
interval.

## 5. Final-block and truncation contract

If the certificate crosses inside a computed block, the algorithm forms an
orthonormal basis `H_t` for the projection of the current and remaining block
products onto the complement of `Q_t`. The final range is

`Q_star = [Q_t, H_t]`.

After `Q_star` is fixed, the implementation performs no more applications of
`A`. It forms the complete projected core through at most one terminal block
application

`B_star^T = A^T Q_star`.

The rows associated with `H_t` provide the residual decrease

`Delta_t = ||H_t^T A||_F^2`.

The exact core-truncation budget is

`epsilon_star^2 = tau^2 - U_t + Delta_t`.

The smallest rank whose projected-core singular-value tail fits this budget is
returned. The implementation must compute the final error accounting from the
orthogonal identity

`||A - Q_star B_k||_F^2 = ||(I - Q_star Q_star^T) A||_F^2 + ||B_star - B_k||_F^2`.

For finite precision, the algorithm substitutes an upper residual bound, a
lower bound on `Delta_t`, and an upper bound on the computed SVD tail. If no
rank passes the conservative test, it must retry at tighter accuracy or return
an explicit numerical-failure status; it must never report success by clipping
a negative budget.

## 6. Termination and accounting

The state machine has four terminal routes:

1. the output basis fills the ambient output space;
2. the final unused input direction is processed;
3. the exact residual direction is zero, or its finite-precision counterpart is
   handled by the documented threshold/refactor policy;
4. the certificate boundary is certified.

Separate counters are mandatory for:

- directions processed by the sequential stopping rule;
- columns actually multiplied by `A`;
- block calls to `A`;
- columns multiplied by `A^T`;
- block calls to `A^T`.

Counting a block of width `s` as `s` vector products is part of the public
contract. Every operator call must pass through one counting wrapper so that
the library, CLI, bindings, baselines, and experiments use identical semantics.

## 7. Exact versus floating-point claims

The paper's probability, rank, and product theorems apply to the exact
algorithm. Versioned software documentation must report separately:

- the exact theoretical guarantee;
- which finite-precision enclosures were enabled;
- whether every enclosure was actually certified;
- any fallback, retry, or threshold event;
- the directly measured final error when an explicit or known-spectrum operator
  makes that measurement possible.

A normal FP64 run may be described as implementing the paper's safeguards, but
it must not be labelled a rigorous floating-point certificate until all special
function, matrix-product, QR, inversion, residual-decrease, and SVD-tail error
bounds are closed end to end.
